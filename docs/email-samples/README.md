# Email sample review pack

Open `index.html` to review all eight production email templates in one browser page. Each sample also has an individual HTML preview, rendered PNG, and an `.eml` file for import into an email client.

All names, dates, links, addresses, and tokens in this folder are fictional review data. Regenerate the pack after changing a template with:

```bash
cd apps/api
.venv/bin/python scripts/generate_email_samples.py --output ../../docs/email-samples
```
